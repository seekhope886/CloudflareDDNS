MQTT 協定教學

輕量級物聯網訊息的傳遞協定

ESP32 C3 Super Mini

什麼是 MQTT？

Message Queue Telemetry Transport

一種輕量級、基于發布/訂閱的物聯網通訊協定，專為低頻寬、高延遲或不可靠的網路環境設計。

Broker 中介服務器

MQTT 的核心组件，負責接收發布者的訊息並轉發給訂閱者。常見的 Broker 有 Mosquitto、EMQX、HiveMQ 等。

QoS 服務品質

MQTT 提供三種 QoS 等级：0（最多一次）、1（至少一次）、2（恰好一次），可根據應用需求選擇。

發布 (Publish)

發布者將訊息發送到特定的主題 (Topic)。訊息包含主題名稱和内容負載。

Arduino 
// 引入 MQTT 庫
#include <PubSubClient.h>

// 設置主題和訊息
const char topic[] = "home/sensor/temperature";
const char message[] = "25.5";

// 發布訊息到 Broker
mqttClient.publish(topic, message);

// 帶 QoS 的發布
mqttClient.publish(topic, message, true); // retain = true
  • Topic 命名規範： 使用斜杠分隔層级，如 home/livingroom/temperature
  • Wildcard 通配符： # 匹配多層，+ 匹配單層
  • Retain 保留訊息： 設置為 true 時，新訂閱者會立即收到最後一條訊息

訂閱 (Subscribe)

訂閱者向 Broker 註冊感興趣的主題。當有新的訊息發布到該主題時，Broker 會將訊息推送给訂閱者。

Arduino 
// 訂閱單個主題
mqttClient.subscribe("home/lights");

// 訂閱多个主題
mqttClient.subscribe("home/sensor/#");   // 所有 home/sensor 子主题
mqttClient.subscribe("home/+/temperature"); // 所有房间的温度

// 回調函数處理接收到的訊息
void callback(char* topic, byte* payload, unsigned int length) {
  payload[length] = '\0';  // 确保字串结尾
  String msg = String((char*)payload);
  Serial.println(msg);
}

通配符 #

多層通配符，匹配該主題下的所有子主題。例如 home/# 匹配 home/sensor、home/lights/on 等。

通配符 +

單層通配符，匹配一層主題。例如 home/+/temperature 匹配 home/livingroom/temperature。

QoS 服務質量等級

QoS 0 - 最多一次

發送一次，不確認。適用于對可靠性要求不高的場景，如周期性的傳感器數據。

mqttClient.publish("topic", "msg", false);

QoS 1 - 至少一次

確認機制，確保訊息至少送達一次。可能出現重複送達。

mqttClient.publish("topic", "msg", false, 1);

QoS 2 - 恰好一次

四次握手，確保訊息恰好送達一次。適用于關鍵指令或計费交易。

mqttClient.publish("topic", "msg", false, 2);

常用 MQTT Broker

  • M

    Mosquitto

    開源輕量級 broker，適合學習和小規模部署。Docker 安裝：docker run -it -p 1883:1883 -p 9001:9001 eclipse-mosquitto

  • E

    EMQX

    高性能開源 MQTT broker，支持億級連接。提供雲端托管服務。

  • H

    HiveMQ

    企業級 MQTT broker，有免費社區版。支持 MQTT 5.0 和 WebSocket。

  • C

    CloudMQTT

    雲端托管 MQTT 服務，有免费方案。適合快速原型開發。

ESP32 連接範例

Arduino 
#include <WiFi.h>
#include <PubSubClient.h>

const char* ssid = "Your_WiFi_SSID";
const char* password = "Your_WiFi_Password";
const char* mqtt_server = "broker.emqx.io";
const int mqtt_port = 1883;

WiFiClient espClient;
PubSubClient mqttClient(espClient);

void setup() {
  Serial.begin(115200);
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
  }
  mqttClient.setServer(mqtt_server, mqtt_port);
  mqttClient.setCallback(callback);

  while (!mqttClient.connected()) {
    if (mqttClient.connect("ESP32Client")) {
      mqttClient.subscribe("test/topic");
    }
    delay(1000);
  }
}

void loop() {
  mqttClient.loop();
}
